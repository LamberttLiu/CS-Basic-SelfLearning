# CS-Basic-SelfLearning · 数据结构与操作系统自学笔记

本专栏面向已经掌握 C 语言基础、希望建立数据结构与操作系统知识框架的自学者。

项目始于 2022 年，保留了学习过程中的图解、代码片段与概念整理。

**当前收尾范围：数据结构与算法（C 语言）＋操作系统。** 目标是在明确范围内形成可阅读、可练习、可复查的学习路径。

> 本仓库仍处于整理阶段，尚不能视为完整教程。历史笔记主要参考王道课程，也包含其他资料；正文、插图和代码的来源正在逐项梳理。文章目录只区分“未完成”和“已完成”，按内容是否写齐维护；来源核查与错误修正继续逐篇处理。

前置知识：C 语言的变量、分支与循环、函数、数组、指针和结构体。

1. [数据结构目录](【DSA】数据结构与算法（C语言版本）/README.md)：线性表 → 栈与队列 → 串 → 树 → 图 → 查找 → 排序。
2. [操作系统目录](【OS】操作系统/README.md)：运行机制 → 进程与同步 → 内存 → 文件 → I/O。
3. 每一主题尝试解释一个概念、手推一个例子，并检查实现或适用条件。学习目标、缺口与收尾标准见[项目收尾方案](PROJECT_PLAN.md)。

# 数据结构和算法 DataStructure & Algorithm (C语言实现) 

数据结构和算法，是计算机入门的基础的重中之重，是在完成一门编程语言（例如C语言）后可以掌握的基础课程。由于C语言是一门语法稍微简单，并且多数使用作为编程入门的语言。因此，本内容采用C语言作为数据结构和算法实现的语言。

**前置需求**：
- C语言中基本数据类型、表达式、变量；
- 分支、循环；
- 函数调用与被调用；
- 数组、指针，字符串，结构体，重定义；

# 操作系统 Operating System
**操作系统是**控制管理计算机系统的硬软件，分配调度资源的**系统软件**，向上为上层软件提供接口，向下控制管理系统资源，是整个应用软件层和硬件层的中间过渡。操作系统课程分为四个部分：进程管理、内存管理、文件管理、I/O管理。
理解操作系统的功能和细节，常常需要将操作系统和现实世界联系起来，在这个课程中，我常常会摒弃掉一些无比复杂和专业性的词语、工整排比的特征分析，通过以现实世界的例子来理解，操作系统究竟干了哪些事情。

**具体章节**：见[操作系统目录](【OS】操作系统/README.md)。目录使用勾选标记“未完成 / 已完成”。
